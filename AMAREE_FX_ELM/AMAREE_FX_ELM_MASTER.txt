PART A: FOUNDATIONAL DEFINITIONS
================================================================================

A1. ECCENTRIC LIQUIDATION: OPERATIONAL DEFINITION
--------------------------------------------------

Eccentric Liquidation (EL) is a PRICE-ACTION EVENT characterized by:

1. UNUSUAL PRICE EXCURSION: A rapid, non-linear movement that exceeds the
   instrument's typical volatility envelope by >= 1.6x the 20-period ATR
   measured from the highest timeframe in analysis.

2. LIQUIDITY RAID EVIDENCE: The excursion sweeps a clearly defined liquidity
   pool (stop cluster) identified by:
   - Previous swing high/low with visible wicks
   - Order block from prior displacement
   - Fair Value Gap (FVG) from imbalance
   - Volume spike (when available)

3. REJECTION OR RECLAIM: Price returns >= 61.8% of the excursion distance
   within 3 candles (timeframe-dependent) OR reclaims the pre-excursion
   structure level with momentum.

4. DISPLACEMENT CONFIRMATION: The rejection creates a new market structure
   shift (higher high/low or lower high/low) within 5 candles of the
   eccentric event.

5. MSS/BOS ALIGNMENT: The event occurs at or beyond a Market Structure
   Shift (MSS) or Break of Structure (BOS) level from the next higher
   timeframe.

OPERATIONAL FORMULA:
EL = (Excursion > 1.6x ATR20) AND (Liquidity Sweep) AND (Rejection >= 61.8%)
     AND (Structure Shift) AND (MSS/BOS Alignment)

EXCLUSIONS (Not EL):
- News-driven gaps without liquidity context
- Regular retracements within established trends
- Range expansions without structural follow-through
- Low-volume spikes in illiquid pairs
- Pre-planned economic event reactions


A2. RELATIONSHIP TO ESTABLISHED SMC/ICT CONCEPTS
--------------------------------------------------

ESTABLISHED CONCEPTS (SMC/ICT):
- Liquidity: Areas where stop orders cluster (above highs, below lows)
- Market Structure: Series of higher highs/lows (bullish) or lower highs/lows (bearish)
- Break of Structure (BOS): Price moves beyond previous swing extreme
- Change of Character (CHOCH): Price behavior shifts from trend to range or vice versa
- Fair Value Gap (FVG): Three-candle imbalance creating unfilled liquidity
- Order Block: Institutional order clusters from prior displacement
- Mitigation Block: Counter-trend orders from FVG fills
- Discount/Premium: Price relative to fair value
- Kill Zone: High-probability reversal areas (London Open, New York Open)

NEW HYPOTHESES (ELM-SPECIFIC):
- Eccentric Liquidation: The specific pattern defined above
- 1.6x ATR Threshold: Quantified excursion boundary
- 61.8% Rejection Rule: Fibonacci-based validation
- Multi-Timeframe MSS Alignment: Cross-timeframe confirmation requirement
- Volatility-Scaled Parameters: Dynamic adaptation system

SEPARATION PROTOCOL:
When analyzing any price action:
1. First classify using ESTABLISHED SMC/ICT concepts
2. Then check if NEW ELM hypotheses apply
3. Never force ELM interpretation on standard patterns
4. Document which framework each observation belongs to


A3. MARKET PHENOMENA CLASSIFICATION
------------------------------------

PHENOMENON          | SMC/ICT TERM    | ELM CLASSIFICATION | TRADABLE?
-------------------|-----------------|---------------------|----------
Sharp reversal      | Liquidity Raid  | Potential EL        | Yes (with confirmation)
Stop hunt          | Liquidity Sweep | EL Component        | Yes
Breakout           | BOS             | Not EL (continuation)| Yes (different rules)
False breakout     | FVG Fill        | EL Candidate        | Yes
Range expansion   | -               | Not EL              | No
News spike         | -               | Excluded            | No
Trend continuation | -               | Not EL              | Yes (different rules)


A4. HYPOTHESIS SEPARATION PROTOCOL
-----------------------------------

RULE 1: Every observation must be classifiable under SMC/ICT BEFORE applying
        ELM hypotheses.

RULE 2: ELM hypotheses only apply when ALL FIVE criteria from A1 are met.

RULE 3: If a pattern fits SMC/ICT but not ELM, trade using SMC/ICT rules.

RULE 4: If a pattern fits both, prioritize ELM only if it offers superior
        reward-to-risk based on backtested performance.

RULE 5: Document the classification path for every analysis.

B2. TOP-DOWN ANALYSIS PROTOCOL
-------------------------------

STEP 1: Highest Timeframe (HTF) Analysis
  a. Identify market structure (trend/range)
  b. Map major liquidity levels (above highs, below lows)
  c. Note MSS/BOS points from prior swings
  d. Establish volatility baseline (ATR20)
  e. Define fair value zone (middle 50% of recent range)

STEP 2: Intermediate Timeframe (ITF) Analysis
  a. Confirm HTF structure alignment
  b. Identify internal liquidity pools
  c. Look for FVGs and order blocks
  d. Check for eccentric events meeting HTF criteria
  e. Validate rejection quality

STEP 3: Execution Timeframe (ETF) Analysis
  a. Pinpoint exact entry triggers
  b. Define stop-loss placement
  c. Calculate TP levels
  d. Verify all EL criteria
  e. Check for conflicting signals

TIMEFRAME PRIORITY:
- If D1 present: D1 -> H4 -> H1
- If H4 present but not D1: H4 -> H1 -> M15
- If H1 present but not H4/D1: H1 -> M15 -> M5
- If M15 present but not higher: M15 -> M5 -> M1

CONTEXT RETAINED:
- HTF liquidity levels
- HTF structure direction
- HTF volatility envelope
- HTF MSS/BOS status

2. Session Context (resets daily)
   - London Open level

3. Timeframe Context (cascades downward)
   - Structure direction

When moving from HTF to ITF to ETF:
- HTF liquidity levels become ITF "external liquidity"
- HTF structure becomes ITF "macro bias"
- HTF volatility becomes ITF "scaling factor"
- ITF observations become ETF "confirmation requirements"

PART C: ENTRY CONDITIONS & VALIDATION
================================================================================

C1. BULLISH ECCENTRIC LIQUIDATION SETUP
---------------------------------------

REQUIREMENTS (ALL MUST BE MET):

1. EXCURSION BELOW STRUCTURE:
   - Price sweeps below a clearly defined liquidity pool
   - Sweep distance >= 1.6x HTF ATR20
   - Liquidity pool = previous swing low OR order block low

2. REJECTION EVIDENCE:
   - Price returns >= 61.8% of sweep distance within 3 candles
   - Rejection candle has body >= 60% of total range
   - Rejection occurs with increasing volume (when available)

3. DISPLACEMENT CONFIRMATION:
   - Price creates new higher low above the swept liquidity
   - OR price reclaims the pre-sweep structure level
   - Must occur within 5 candles of rejection

4. MSS/BOS ALIGNMENT:
   - The swept low must be at or below a HTF MSS level
   - OR the rejection must create a BOS above HTF structure

5. STRUCTURAL VALIDATION:
   - HTF structure must be bullish (higher highs/lows)
   - OR neutral with bullish bias from ITF

ENTRY TRIGGER:
- Price breaks above the high of the rejection candle
- OR price retests the swept liquidity as support with bullish order flow


C2. BEARISH ECCENTRIC LIQUIDATION SETUP
----------------------------------------

REQUIREMENTS (ALL MUST BE MET):

1. EXCURSION ABOVE STRUCTURE:
   - Price sweeps above a clearly defined liquidity pool
   - Sweep distance >= 1.6x HTF ATR20
   - Liquidity pool = previous swing high OR order block high

2. REJECTION EVIDENCE:
   - Price returns >= 61.8% of sweep distance within 3 candles
   - Rejection candle has body >= 60% of total range
   - Rejection occurs with increasing volume (when available)

3. DISPLACEMENT CONFIRMATION:
   - Price creates new lower high below the swept liquidity
   - OR price reclaims the pre-sweep structure level
   - Must occur within 5 candles of rejection

4. MSS/BOS ALIGNMENT:
   - The swept high must be at or above a HTF MSS level
   - OR the rejection must create a BOS below HTF structure

5. STRUCTURAL VALIDATION:
   - HTF structure must be bearish (lower highs/lows)
   - OR neutral with bearish bias from ITF

ENTRY TRIGGER:
- Price breaks below the low of the rejection candle
- OR price retests the swept liquidity as resistance with bearish order flow


C3. CONFIRMATION HIERARCHY
---------------------------

LEVEL 1 (MANDATORY - All Required):
- Excursion >= 1.6x ATR20
- Liquidity sweep identified
- Rejection >= 61.8%

LEVEL 2 (STRONG CONFIRMATION - 2 of 3 Required):
- Displacement within 5 candles
- MSS/BOS alignment
- Volume increase on rejection

LEVEL 3 (OPTIMAL CONFIRMATION - 1 of 2 Required):
- FVG present in direction of trade
- Order block in direction of trade

CONFIRMATION SCORE:
- Level 1 only: 33% - WAIT FOR MORE CONFIRMATION
- Level 1 + Level 2 (2/3): 66% - TRADE WITH CAUTION
- Level 1 + Level 2 (3/3) + Level 3: 100% - HIGH CONFIDENCE


C4. FALSE SIGNAL FILTERS
------------------------

FILTER 1: Low Volume Filter
- If volume on rejection candle < average of previous 5 candles
- AND no FVG/order block alignment
- => INVALIDATE

FILTER 2: Time Filter
- If eccentric event occurs within 1 hour of known high-impact news
- => INVALIDATE (wait for news to pass)

FILTER 3: Range Filter
- If current HTF range < 50% of 20-day average range
- => INVALIDATE (low volatility environment)

FILTER 4: Structure Filter
- If HTF structure contradicts ITF/ETF signal
- => INVALIDATE (conflicting context)

FILTER 5: Overbought/Oversold Filter
- If price is > 2 standard deviations from 20-period mean (Bollinger)
- AND no displacement confirmation
- => WAIT FOR CONFIRMATION

FILTER 6: Candle State Filter
- If current candle on ETF is still forming (open)
- AND entry trigger not yet met
- => WAIT FOR CANDLE CLOSE


C5. CONTINUATION VS. REVERSAL DISCRIMINATION
---------------------------------------------

REVERSAL SIGNALS (EL Candidate):
- Sweep of opposite structure extreme
- Rejection >= 61.8%
- Displacement creates NEW structure in opposite direction
- MSS alignment from higher timeframe

CONTINUATION SIGNALS (Not EL):
- Sweep of same-direction structure extreme
- Rejection < 50%
- Displacement continues in SAME direction
- BOS alignment (not MSS)

DISCRIMINATION RULES:
1. If displacement creates higher high in uptrend => CONTINUATION
2. If displacement creates lower high in uptrend => POTENTIAL REVERSAL
3. If displacement creates lower low in downtrend => CONTINUATION
4. If displacement creates higher low in downtrend => POTENTIAL REVERSAL

D1. VOLATILITY-SCALED PARAMETERS
--------------------------------

VOLATILITY CLASSIFICATION:
- LOW: Average daily range < 50 pips (e.g., EURGBP, AUDNZD)
- MEDIUM: Average daily range 50-150 pips (e.g., EURUSD, GBPUSD)
- HIGH: Average daily range > 150 pips (e.g., GBPJPY, exotic pairs)

SCALING FACTORS:
- LOW: ATR multiplier = 1.8x, Rejection = 70%
- MEDIUM: ATR multiplier = 1.6x, Rejection = 61.8%
- HIGH: ATR multiplier = 1.4x, Rejection = 50%

XAUUSD SPECIAL:
- ATR multiplier = 2.0x (due to high volatility)
- Rejection = 61.8%
- Additional filter: Check correlation with USD index

SYNTHETIC INDICES (Vol75, Vol100):
- ATR multiplier = 1.2x (extremely volatile)
- Rejection = 50%
- Timeframe: Maximum H1 (no higher)
- Special: Ignore traditional SMC structure, focus on momentum


D2. QUOTE PRECISION & SPREAD ADAPTATION
----------------------------------------

PRECISION HANDLING:
- JPY pairs: 3 decimal places (0.001 = 1 pip)
- Standard pairs: 5 decimal places (0.00001 = 0.1 pip)
- XAUUSD: 3 decimal places (0.001 = 10 cents)
- Synthetics: 2 decimal places

SPREAD ADJUSTMENT:
- Entry buffer = spread + 1 pip (minimum)
- Stop-loss buffer = spread + 2 pips
- TP buffer = spread (no additional buffer)

TRANSACTION COST INTEGRATION:
- Total cost = spread + commission + slippage
- Minimum R:R adjustment = cost / stop distance
- If adjusted R:R < 1.5 => INVALIDATE


D3. TRANSACTION COST INTEGRATION
---------------------------------

COST CALCULATION:
- Spread: Current bid/ask difference
- Commission: Per lot cost (if known)
- Slippage: Estimated based on volatility (0.5-2 pips typical)

R:R ADJUSTMENT:
Original R:R = (TP - Entry) / (Entry - SL)
Adjusted R:R = (TP - Entry - Total Cost) / (Entry - SL + Total Cost)

MINIMUM ACCEPTABLE:
- Adjusted R:R >= 1.5 for all trades
- Adjusted R:R >= 2.0 for counter-trend trades


D4. CROSS-PAIR CONSISTENCY RULES
----------------------------------

CORRELATION CHECK:
- If trading EURUSD, check GBPUSD, USDJPY for consistency
- If trading XAUUSD, check USD index
- If 2 of 3 correlated pairs show opposite signal => WAIT

VOLATILITY NORMALIZATION:
- Compare current ATR to 30-day average
- If current ATR > 2x average => Use higher volatility parameters
- If current ATR < 0.5x average => Use lower volatility parameters

INSTRUMENT-SPECIFIC RULES:
- JPY pairs: Watch for BOJ intervention zones
- Exotics: Wider stops, lower position sizes
- Majors: Standard parameters
- Crosses: Check both currency components

E2. RISK MANAGEMENT PROTOCOL
-----------------------------

POSITION SIZING:
- Risk per trade: 0.5-2% of account (user-defined)
- Position size = (Account Risk) / (Stop Distance in Currency Units)
- Maximum position size: 10% of account equity

STOP-LOSS PLACEMENT:
- Bullish: Below the most recent swing low OR below the swept liquidity
- Bearish: Above the most recent swing high OR above the swept liquidity
- Minimum distance: 1.5x average spread
- Maximum distance: 3x ATR of ETF

TAKE-PROFIT STRUCTURE:
- TP1: 1x risk (1:1 R:R) - Always taken
- TP2: 2x risk (2:1 R:R) - Move SL to breakeven
- TP3: 3x risk (3:1 R:R) - Optional, requires strong confirmation

TRAILING STOP:
- Activate after TP1 hit
- Trail by: 1x ATR of ETF
- OR use manual trailing based on structure

DRAWDOWN MANAGEMENT:
- Daily max loss: 5% of account
- Weekly max loss: 10% of account
- Monthly max loss: 15% of account
- After max loss reached: STOP TRADING


E3. STRUCTURAL INVALIDATION RULES
----------------------------------

AUTOMATIC INVALIDATION:
- Price closes beyond the swept liquidity level in opposite direction
- HTF creates new structure against the trade bias
- Time-based: If entry trigger not met within defined window

MANUAL INVALIDATION:
- News event contradicts setup
- Volume analysis shows distribution/accumulation against bias
- Correlated pairs show opposite movement

INVALIDATION LEVELS:
- Bullish trade: Invalid if price closes below entry candle low
- Bearish trade: Invalid if price closes above entry candle high
- Time window: Typically 2-4 candles on ETF


E4. NEXT ACTION LOGIC
---------------------

DECISION TREE:

1. Are all Level 1 conditions met?
   - NO => NO TRADE
   - YES => Go to 2

2. Is confirmation score >= 66%?
   - NO => WAIT FOR CONFIRMATION
   - YES => Go to 3

3. Are all filters passed?
   - NO => INVALIDATED
   - YES => Go to 4

4. Is current candle closed?
   - NO => WAIT FOR CANDLE CLOSE
   - YES => Go to 5

5. Is entry trigger met?
   - NO => WAIT FOR TRIGGER
   - YES => ENTER TRADE

POST-ENTRY ACTIONS:
- Monitor TP1: If hit, move SL to breakeven
- Monitor TP2: If hit, trail stop
- Monitor structural invalidation: If triggered, exit immediately

PART F: SCREENSHOT INTERPRETATION
================================================================================

F1. VISUAL PATTERN RECOGNITION
-------------------------------

IDENTIFIABLE ELEMENTS:
- Swing Highs: Candles with higher highs than N candles on each side
- Swing Lows: Candles with lower lows than N candles on each side
- Liquidity Pools: Areas with visible wicks beyond body
- FVGs: 3-candle pattern with middle candle gap
- Order Blocks: 3-5 candle consolidation before move
- Eccentric Events: Sharp spikes with rapid retracement

VISUAL FILTERS:
- Minimum swing size: 2x average candle body
- Minimum wick size: 30% of candle range
- Minimum FVG size: 1x average candle range


F2. SWING IDENTIFICATION PROTOCOL
----------------------------------

STEP 1: Scan for local extremes
- Look left: N candles (N = 5 for M15, 10 for H1, 20 for H4)
- Look right: N candles
- If highest/lowest in both directions => Swing

STEP 2: Classify swing strength
- Weak: Swing with small wicks, low volume
- Strong: Swing with large wicks, high volume
- Extreme: Swing with > 2x average range

STEP 3: Connect swings to identify structure
- Bullish: Higher highs AND higher lows
- Bearish: Lower highs AND lower lows
- Range: Equal highs AND equal lows


F3. LIQUIDITY MAPPING RULES
----------------------------

EXTERNAL LIQUIDITY:
- Above: Previous swing highs
- Below: Previous swing lows
- Strength: Based on wick size and volume

INTERNAL LIQUIDITY:
- FVGs within range
- Order blocks from prior moves
- Mitigation blocks from FVG fills

LIQUIDITY STRENGTH SCORING:
- Wick size: 1-10 (10 = largest)
- Volume: 1-10 (10 = highest)
- Recency: 1-10 (10 = most recent)
- Total score: Average of three


F4. CANDLE STATE HANDLING
--------------------------

OPEN CANDLE RULES:
- Never assume direction
- Never assume close price
- Can identify: Current high/low, body size so far
- Cannot identify: Final rejection, confirmed displacement

CLOSED CANDLE RULES:
- Can identify: All patterns, all levels
- Can confirm: Rejection, displacement, structure shifts

MIXED STATE (Multiple Screenshots):
- Use most recent closed candle for confirmation
- Note open candles as "forming" in analysis
- If open candle invalidates setup, flag as "AT RISK"


F5. EVIDENCE VS. INTERPRETATION SEPARATION
-------------------------------------------

EVIDENCE (OBJECTIVE):
- Price levels (highs, lows, closes)
- Wick sizes
- Candle ranges
- Volume values
- Time stamps
- Identifiable patterns (FVG, order blocks)

INTERPRETATION (SUBJECTIVE):
- Liquidity strength
- Market bias
- Probability assessments
- Trade decisions

RULES:
1. Always state evidence first
2. Then provide interpretation
3. Never present interpretation as fact
4. Use phrases: "Evidence shows...", "This suggests...", "Interpretation:..."
